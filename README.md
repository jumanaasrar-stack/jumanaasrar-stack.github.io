# Jumana Asrar | Research, UX, AI & Product Management

Jumana Asrar's professional portfolio, including selected work, research methods, AI and product coursework, experience, and contact information.

## Publish the website

Open repository Settings > Pages. Under Build and deployment, choose Deploy from a branch, then main and / (root), and click Save.

Website address after deployment: https://jumanaasrar-stack.github.io/

## Update the portfolio

Edit index.html for homepage content, script.js for case studies and interactions, and style.css for the design. Images and logos are in assets/. Commits to main are published automatically once GitHub Pages is enabled.
